# SAMS - SMart Agriculture Monitoring System

## Overview
SAMS is an IoT application that lets users monitor and control their farms irrigation systems. It monitors soil moisture sensors in real time and controls irrigation valves based on current environmental conditions and user defined parameters.

## Tech Stack
* **Frontend:** React, TypeScript, Vite
* **Backend:** Node.js, Express, TypeScript
* **Database:** PostgreSQL
* **Simulator:** Node.js script for simulating IoT devices
